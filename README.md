# Galleria — Morocco

Official storefront source for **Galleria**: original Moroccan photographic prints and **Villa Nova by Galleria** handcrafted candles.

## Catalog
- Amber / mini scented ceramic candle — **99 MAD**
- Oud / large scented ceramic candle — **149 MAD**
- Photo prints made to order — frame finish: walnut, white or black; size: 50 × 70 cm or smaller size (confirmation required)

Customers order via WhatsApp at **+212 618 401 389**. The storefront supports French, English and Arabic.

## Launch instructions
Upload the **contents** of the prepared `galleria-github-ready.zip` directly to the repository root, including all HTML files, `style.css`, JavaScript files and the `assets/` directory. Do **not** upload only `index.html`: images, CSS and behavior depend on the other files.

Then go to **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save. After GitHub Pages is enabled, the expected address is `https://faissal1photographer-sys.github.io/galleria-ma/`.

The GitHub Pages URL is only considered live once Pages finishes deploying; the domain `galleria.ma` is a separate DNS setup.
