# Galleria — boutique

This repository contains a self-contained **Galleria** web storefront in `index.html`, with the olive/ivory design, French/English/Arabic switcher, working cart and WhatsApp ordering.

## Product and ordering setup
- **Villa Nova by Galleria — Amber mini:** 99 MAD
- **Villa Nova by Galleria — Oud large:** 149 MAD
- **Photo prints made to order:** customer selects photography, frame finish (walnut/black/white) and size (50 × 70 cm or small, size to be confirmed). Print prices and delivery are confirmed manually.
- Orders open **WhatsApp +212 618 401 389**, with selections, quantities and city, but the buyer must press Send inside WhatsApp.

## Important outstanding items

Those original photos are included in the downloadable Galleria site package shared in ChatGPT; the GitHub connector in this conversation could only write text content. Do not represent the placeholders as the actual candles. For the complete multi-page source and images, copy the contents of the previously supplied `galleria-github-ready.zip` into the repository root, replacing this temporary self-contained preview.

## Enable the live preview
Go to **Settings → Pages → Build and deployment** → select **Deploy from a branch** → branch **main** → folder **/(root)** → **Save**.
The expected address will be https://faissal1photographer-sys.github.io/galleria-ma/ when GitHub Pages reports a successful deployment. The custom `galleria.ma` domain needs separate DNS configuration.

Built with static HTML, CSS, and JavaScript. No payment is charged online.
